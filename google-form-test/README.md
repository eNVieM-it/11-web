# Тест для Google Форми — «Вебтехнології», уроки 4–7

**Що всередині:** 20 питань (одна відповідь / кілька відповідей), 26 балів, з поясненнями.
Матеріал — за сайтом: Урок 4 (Box Model), Урок 5 (адаптивна верстка),
Урок 6 (кросбраузерність та оптимізація), Урок 7 (графіка для вебу).

## Важливо про «підключений акаунт»

У мене немає доступу до вашого Google-акаунта — створити форму *за вас* я не можу.
Натомість тут є **Apps Script, який створює форму у вашому акаунті одним запуском**
(ви виконуєте його під своїм логіном, тому форма належить вам).

## Спосіб А — Python + credentials.json (форма створюється автоматично)

Якщо у вас уже є Desktop-клієнт Google Cloud:

1. Покладіть `credentials.json` у цю папку (`google-form-test/`) — **не в чат** і не в git
   (у `.gitignore` вже додані `credentials.json` / `token.json`).
2. Увімкніть **Google Forms API** у Google Cloud Console для вашого проєкту.
3. Встановіть бібліотеки та запустіть:
   `pip install google-api-python-client google-auth-oauthlib`
   `python create_form.py`
4. **Один раз** відкриється браузер: увійдіть у свій акаунт → **Allow**
   (це обов'язковий інтерактивний вхід — я не можу зробити його за вас;
   сам `credentials.json` є лише ID/secret клієнта, а не доступом до акаунта).
5. Скрипт надрукує посилання на форму. Останній крок вручну: позначте правильні
   відповіді в редакторі (Forms API не вміє quiz grading програмно) —
   ключі в `test-questions.csv`.

## Спосіб Б — Apps Script (без локальних файлів, 2 хвилини)

1. Відкрийте [script.google.com](https://script.google.com) → **New project**.
2. Видаліть стандартний вміст `Code.gs` і вставте **весь файл [CreateGoogleForm.gs](CreateGoogleForm.gs)**.
3. Угорі оберіть функцію **`createTestForm`** → кнопка **Run (▶)**.
4. Google попросить дозволи: **Continue → Allow** (форма створюється у вашому акаунті).
5. Після виконання відкрийте **Executions** (ліва панель) або **View → Logs** —
   там посилання `ФОРМА ГОТОВА: https:// …` (опублікована версія) та `Редактор форми: …`.
6. Відкрийте посилання редактора, перевірте форму, натисніть **Send** і розішліть учням
   посилання на опубліковану версію.

## Що створиться автоматично

- Назва: «Тест: Вебтехнології (уроки 4–7)», режим **Quiz** (автоматична перевірка, бали).
- Поля на початку: «Прізвище та ім’я», «Клас».
- 4 розділи (роздільники сторінок) за уроками, 20 питань.
- Із поясненнями: кожне питання має help-текст із поясненням.

## Якщо автоматична перевірка не спрацювала

Залежно від версії Google Apps Script частина API може не застосуватися
(скрипт це переживає і все одно створює форму). Тоді:

1. У редакторі форми відкрийте кожне питання → **⋮ → Set correct answer** /
   «Позначити правильну відповідь» — правильні варіанти є в
   [test-questions.csv](test-questions.csv) (колонки *Correct*) та
   [test-questions.md](test-questions.md) (рядок «Правильна відповідь»).
2. Увімкніть **Settings → Quizzes → Make this a quiz** та бали за питання.

## Файли

| Файл | Призначення |
|---|---|
| `create_form.py` | Python-скрипт (Forms API) — створює форму з `credentials.json` |
| `CreateGoogleForm.gs` | Apps Script — створює форму у вашому акаунті |
| `test-questions.csv` | Банк питань: питання, варіанти, ключі, пояснення (Excel/Sheets) |
| `test-questions.md` | Той самий банк у зручному для читання вигляді |
| `README.md` | Ця інструкція |

## Змінити кількість/теми

Відредагуйте масив `QUESTIONS` на початку `CreateGoogleForm.gs`
(`title`, `choices`, `correct` — індекси правильних варіантів, `points`) —
і запустіть `createTestForm` ще раз. Попередня форма при цьому не зникне.
