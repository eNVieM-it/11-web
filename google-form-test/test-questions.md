## 1. У якому порядку від центру назовні розташовані шари CSS Box Model?

- A) Content → Padding → Border → Margin
- B) Border → Margin → Content → Padding
- C) Margin → Border → Padding → Content
- D) Padding → Content → Margin → Border

**Правильна відповідь:** A) Content → Padding → Border → Margin

**Пояснення:** Від центру: контент, потім внутрішній відступ (padding), рамка (border) і зовнішній відступ (margin).

## 2. Чим padding відрізняється від margin?

- A) Padding — внутрішній відступ між контентом і рамкою; margin — зовнішній відступ між елементом та іншими елементами
- B) Нічим, це одне й те саме
- C) Padding задає рамку, margin — колір фону
- D) Padding — зовнішній, margin — внутрішній

**Правильна відповідь:** A) Padding — внутрішній відступ між контентом і рамкою; margin — зовнішній відступ між елементом та іншими елементами

**Пояснення:** Padding «роздуває» блок зсередини, margin відсуває його від сусідів ззовні.

## 3. За значення content-box (замовчування) загальна ширина блоку = width + … Оберіть УСІ правильні варіанти:

- A) border
- B) тільки content
- C) padding
- D) margin

**Правильна відповідь:** A) border; C) padding

**Пояснення:** За content-box ширина = width + padding + border. Margin у ширину блоку не входить (він — поза блоком).

## 4. Що робить box-sizing: border-box?

- A) Робить усі блоки однакового кольору
- B) Вимикає рамки на сторінці
- C) Забороняє margin
- D) Включає padding і border у заданий width, тому розмір блоку не «роздувається»

**Правильна відповідь:** D) Включає padding і border у заданий width, тому розмір блоку не «роздувається»

**Пояснення:** З border-box width вже містить padding і border — верстка стає передбачуванішою.

## 5. Які властивості задають рамку (border)? Оберіть УСІ правильні варіанти:

- A) border-style (solid, dashed, dotted…)
- B) border-width
- C) border-radius — заокруглює кути рамки
- D) border-color

**Правильна відповідь:** A) border-style (solid, dashed, dotted…); B) border-width; C) border-radius — заокруглює кути рамки; D) border-color

**Пояснення:** Повний запис: border: 2px solid #333; а border-radius додає заокруглення кутів.

## 6. Що означає принцип Mobile First?

- A) Сайт показується лише на мобільних
- B) Можна не перевіряти сайт на комп’ютері
- C) Спочатку створюємо базові стилі для смартфонів, потім додаємо стилі для більших екранів
- D) Спочатку робимо стилі для великих моніторів

**Правильна відповідь:** C) Спочатку створюємо базові стилі для смартфонів, потім додаємо стилі для більших екранів

**Пояснення:** Mobile First: база — мобільний, далі — розширення для планшетів і десктопів.

## 7. Для чого потрібен мета-тег viewport?

- A) Щоб прискорити завантаження картинок
- B) Щоб мобільний браузер масштабував сторінку під ширину екрана пристрою
- C) Щоб додати заголовок сторінки
- D) Щоб увімкнути темну тему

**Правильна відповідь:** B) Щоб мобільний браузер масштабував сторінку під ширину екрана пристрою

**Пояснення:** Без <meta name="viewport" content="width=device-width, initial-scale=1"> мобільні браузери показують сторінку «зменшеною».

## 8. Коли застосовуються стилі всередині @media?

- A) Тільки для друку сторінки
- B) Тільки коли виконується умова медіазапиту (напр., ширина екрана ≥ 768px)
- C) Лише у темній темі
- D) Завжди, у всіх браузерах

**Правильна відповідь:** B) Тільки коли виконується умова медіазапиту (напр., ширина екрана ≥ 768px)

**Пояснення:** Медіазапити дозволяють мати різні стилі для різних розмірів екрана.

## 9. Які значення може мати flex-direction? Оберіть УСІ правильні варіанти:

- A) row
- B) column
- C) row-reverse
- D) column-reverse

**Правильна відповідь:** A) row; B) column; C) row-reverse; D) column-reverse

**Пояснення:** row/column задають напрям головної осі, а -reverse міняють порядок елементів місцями.

- D) Фіксована ширина 1200px для всього сайту без медіазапитів

## 11. Який рушій (browser engine) до якого браузера? Оберіть правильний рядок:

- A) WebKit — Chrome/Edge; Gecko — Safari; Blink — Firefox
- B) Gecko — Chrome; Blink — Firefox; WebKit — Opera
- C) Усі браузери мають один рушій

- B) Щоб змінити назву сайту
- C) Щоб нові властивості CSS працювали в браузерах із різними рушіями

## 13. Що робить директива @supports?

- A) Створює копію сайту
- B) Прискорює завантаження шрифтів
- C) Забороняє підтримку старих браузерів

- B) Усі картинки завантажуються одночасно при відкритті сторінки

**Правильна відповідь:** C) Зображення, яких не видно на екрані, завантажуються лише при наближенні до них під час прокрутки

## 16. Який формат найкращий для логотипів, іконок та інтерфейсних елементів?

- A) BMP — величезні файли
- B) SVG — векторна графіка: безкінечне масштабування без втрати якості
- C) GIF — 256 кольорів, без масштабування
- D) JPEG — фотоформат із втратами

**Правильна відповідь:** B) SVG — векторна графіка: безкінечне масштабування без втрати якості

## 17. Які формати растра найкращі для фотографій на сучасному сайті?

- A) BMP і TIFF
- B) Тільки PNG-8
- C) WebP / AVIF — значно легші за JPEG за тієї самої якості
- D) GIF

- A) Добре підходить для UI-елементів із чіткими краями
- B) Ідеальний для великих фотографій (завжди менший за JPEG)
- C) Підтримує прозорість (альфа-канал)

**Правильна відповідь:** A) Добре підходить для UI-елементів із чіткими краями; C) Підтримує прозорість (альфа-канал); D) Стиснення без втрат (lossless)
