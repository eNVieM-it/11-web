# Вебтехнології · 10–11 класи

Інтерактивний навчальний курс із 4 уроків. Статичний сайт без збірки:
достатньо відкрити `index.html` у браузері (працює з `file://`).

## Уроки

| Файл | Урок | JS-логіка |
|---|---|---|
| `index.html` | 1. Вебдизайн та структура сайту | `js/app.js` |
| `html-basics.html` | 2. Основи мови HTML5 | `js/html-lesson.js` |
| `css-basics.html` | 3. Каскадні таблиці стилів CSS | `js/css-lesson.js` |
| `box-model.html` | 4. Блочна модель верстки | `js/box-model.js` |

## Структура

```
├── index.html            точка входу
├── favicon.svg
├── docs/                 методичні матеріали (PDF)
├── test/                 smoke-тести (jsdom), не потрібні для роботи сайту
├── js/
│   ├── core.js           спільне ядро інтерфейсу (усі сторінки)
│   ├── sandbox.js        спільна логіка практикумів (усі сторінки)
│   ├── app.js            Урок 1
│   ├── html-lesson.js    Урок 2
│   ├── css-lesson.js     Урок 3
│   └── box-model.js      Урок 4
└── styles/
    ├── main.css          змінні, теми, хедер/футер, акордеони
    ├── hero.css
    ├── modules.css       картки, кнопки, тренажери
    ├── responsive.css    брейкпоінти
    ├── html-lesson.css   Урок 2
    └── css-lesson.css    Уроки 3 і 4
```

## Архітектура

- **`js/core.js`** — єдине джерело системних компонентів: перемикач теми
  день/ніч (з урахуванням `prefers-color-scheme`), меню «Уроки курсу»,
  бургер-навігація, підсвітка активного пункту змісту, смуга прогресу читання,
  акордеони. Підключається **на всіх** сторінках перед специфічним скриптом.
- **`js/sandbox.js`** — спільна логіка практикумів: рендер коду в iframe
  (`srcdoc`, без витоку `Blob URL`), повноекранний режим (кнопки + `Esc` +
  deep-link `?fullscreen=1`), пісочниця з вкладками та автозапуском (debounce).
- Скрипти сторінок не дублюють ці функції, а лише викликають їх на `DOMContentLoaded`.

## Версії ассетів

Усі підключення мають параметр `?v=N` для інвалідації кешу браузера.
Схема: `main.css?v=8`, спільні `hero|modules|responsive.css?v=6`,
урокові `html-lesson.css?v=4`, `css-lesson.css?v=5`,
`core.js?v=1`, `sandbox.js?v=1`, урокові JS — `?v=6`.

**Після редагування CSS/JS піднімайте номер `?v=`**, інакше браузер
покаже застарілу закешовану версію.

## Налаштування спільного ядра

У `js/core.js` об'єкт `CORE_CONFIG`:

```js
var CORE_CONFIG = {
  navHighlightOffset: 130,   // зсув підсвітки пункту меню, px
  themeStorageKey: 'site_theme',
  defaultTheme: 'light'
};
```

## Тести

Smoke-тест перевіряє синтаксис, порядок підключень, відсутність дублювання
та поведінку інтерфейсу всіх 4 сторінок у jsdom.

```bash
npm install
npm test
```

98 перевірок: підключення `core.js`, ініціалізація теми/меню/акордеонів,
перемикання теми, фулскрин-режим пісочниць, рендер `iframe.srcdoc`.

## Публікація на GitHub

Сайт уже опубліковано через GitHub Pages. Розділ — для тих, хто оновлює
його надалі.

`node_modules/` внесений у `.gitignore` і не потрапить у репозиторій.
Папка з'явилася локально разом з `npm install` (для smoke-тестів) — на сайт
вона не потрібна.

### Крок 0. Встановіть Git (якщо ще не встановлено)

```powershell
winget install Git.Git
```

Після цього перезапустіть термінал (або VS Code), щоб `git` з'явився в PATH.

### Крок 1. Заберіть оновлену версію проєкту

Найкраще — клонувати репозиторій і скопіювати в нього зміни з `e:\11 web`,
або одразу працювати в клоні:

```bash
cd e:\
git clone https://github.com/eNVieM-it/11-web.git
```

Якщо хочете залишити робочу папку `e:\11 web`, підключіть її до
наявного репозиторію:

```bash
cd "e:\11 web"
git init
git remote add origin https://github.com/eNVieM-it/11-web.git
git fetch origin
git branch --set-upstream-to=origin/main main   # або main/master — як у вас
```

### Крок 2. Закомітьте та запушіть

```bash
git add .
git status            # перевір: у списку НЕ має бути node_modules/
git commit -m "Опис зміни"
git push
```

Якщо `git push` відхилить через «non-fast-forward» (бо в репозиторії є
коміти, яких немає локально), спочатку підтягніть їх:

```bash
git pull origin main --rebase
git push
```

Сайт оновиться за 1–2 хвилини.

### Якщо репозиторій треба створити з нуля

github.com → **New repository**, назва `veb-tehnologiyi`, і **зніміть**
галочки «Add a README file» та «Add .gitignore» — інакше виникнуть
конфлікти при першому пуші, бо все це вже є локально.

## Особливості проєкту під Pages

- Усі шляхи **відносні** (`styles/main.css`, `js/core.js`), тому сайт
  однаково працює і на GitHub Pages, і з локального `file://`, і на
  будь-якому хостингу. Нічого переробляти не потрібно.
- Файл `.nojekyll` створено — він вимикає обробку Jekyll, щоб Pages
  не фільтрував файли з підкресленням.
- Тести (`test/`) і `package.json` потрапляють у репозиторій, але
  на сайт не впливають.
- Ключ налаштування Pages: **Settings → Pages → Source: Deploy from a
  branch**, branch **main**, folder **/ (root)**.

### 📄 PDF у папці `docs/`

Файл `docs/veb-tehnologiyi.pdf` (50 МБ) **не входить у репозиторій** — папка
`docs/*.pdf` додана в `.gitignore`. Файл лишається локально, у репозиторій
його немає.

Якщо PDF уже був закомічений раніше, приберіть його з відстеження один раз:

```bash
git rm --cached docs/veb-tehnologiyi.pdf
git commit -m "Прибрати PDF з репозиторію"
git push
```

Файл при цьому залишиться на вашому диску.
