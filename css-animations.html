Урок 9 · CSS transition, transform та @keyframes (§ 3.2 + Практична №8)

Анімаційні ефекти та переходи в CSS

Анімація оживляє веб-сторінку: кнопки м’яко реагують на курсор, картки плавно підіймаються, а індикатори показують, що сайт працює. І найголовніше — усе це можна створити на чистому CSS без жодного рядка JavaScript! Урок побудовано так, щоб ви могли легко розібратися самостійно: на кожне правило є живий приклад і тренажер.

Розділ 1 · Основи плавного руху

Як працюють transition та transform?

Найпростіший спосіб додати динаміку на сайт — змінювати вигляд елемента при наведенні курсора (:hover). Щоб зміна була не різким «стрибком», а плавним перетіканням, використовують властивість transition.

💡 Проста аналогія для розуміння

Уявіть лампу в кімнаті. Без transition вона працює як звичайний вимикач: клац — і колір чи розмір кнопки миттєво «перескочив». Із transition вона працює як плавний регулятор яскравості (димер): браузер сам домальовує всі проміжні кадри між старим і новим станом!

❌ БЕЗ transition (різкий стрибок)

0 секунд

Наведіть курсор на кнопку — вона змінює колір, форму і позицію миттєво, за один кадр: 

.btn:hover {
  background: #ff4732;
  transform: translateY(-6px) scale(1.06);
  border-radius: 999px;
}

✅ ІЗ transition (плавний перехід)

0.35s ease

Додаємо лише 1 рядок у базовий клас кнопки — і той самий ефект стає м’яким і приємним: 

.btn {
  transition: transform 0.35s ease,
              background-color 0.35s ease,
              border-radius 0.35s ease;
}

🧩 Шпаргалка: з чого складається запис transition

Формула 4 частин

Повний короткий запис: transition: transform 0.35s ease-out 0.1s;

1. transform Що анімуємо? Назва властивості (або all — усі змінені властивості, хоча краще вказувати точно).
2. 0.35s Як довго? Тривалість переходу у секундах (0.35s) або мілісекундах (350ms). Обов’язковий параметр!
3. ease-out Як прискорюється? Функція часу (динаміка): linear, ease, ease-in, ease-out.
4. 0.1s Пауза перед стартом (необов’язково). За замовчуванням 0s — старт одразу.

🔄 4 головні трансформації (transform)

Властивість transform змінює положення, розмір або кут елемента, не зсуваючи сусідні блоки на сторінці. Наведіть курсор (або натисніть на смартфоні) на кожну картку, щоб побачити трансформацію в дії:

MOVE

1. Зсув — translate()

Зсуває елемент по осях X (вправо/вліво) та Y (вниз/вгору).

transform: translate(28px, -14px);
ZOOM

2. Масштаб — scale()

1 = 100%, 1.35 = збільшити на 35%, 0.9 = зменшити.

transform: scale(1.35);
TURN

3. Поворот — rotate()

Обертає елемент за годинниковою (+deg) або проти (-deg).

transform: rotate(45deg);
SKEW

4. Нахил — skew()

Нахиляє фігуру вздовж горизонтальної чи вертикальної осі.

transform: skewX(-18deg);
Інтерактивний експеримент · с. 94 підручника

🏁 Забіг функцій часу (timing-function)

Готові до старту! Натисніть кнопку, щоб порівняти 5 кривих швидкості за однакові 2 секунди:

linear Рівномірно, без прискорення
ease Плавний старт → швидше → м’який фініш
ease-in Повільний старт, розгін у кінці
ease-out Швидкий старт, м’яке гальмування
ease-in-out Повільно на початку і в кінці

Ключові кадри @keyframes та animation

Якщо transition вміє лише плавно переходити з точки А в точку Б при наведенні, то @keyframes дозволяє написати цілий міні-мультфільм із проміжними кадрами, який запускається сам і може повторюватися нескінченно.

Критерій порівняння transition (Перехід) animation + @keyframes
Кількість станів Лише 2 стани: початковий (А) → кінцевий (Б) Будь-яка кількість кадрів: 0%, 25%, 50%, 75%, 100%
Як запускається? Потрібна подія (наприклад, наведення :hover або фокус) Може запускатися автоматично одразу після відкриття сторінки
Повторення (цикл) Спрацьовує 1 раз на кожну дію Можна повторювати N разів або нескінченно (infinite)
Типове застосування Кнопки, посилання, збільшення фото в галереї, картки Індикатори завантаження, пульсація банерів, обертання, біжучий рядок

📋 Алгоритм створення CSS-анімації за 3 кроки (с. 90 підручника)

КРОК 1

Оголошуємо @keyframes і назву

Придумуємо зрозумілу англійську назву без пробілів (наприклад, simpleAnimation або spin) і пишемо правило @keyframes назва { ... }.

КРОК 2

Прописуємо ключові кадри (0% → 100%)

Усередині фігурних дужок задаємо стилі для старту (0%), фінішу (100%) та скільки завгодно проміжних точок (25%, 50%, 75%).

КРОК 3

Підключаємо через animation

У CSS-класі елемента вказуємо назву анімації, її тривалість та параметри повторення, наприклад: animation: spin 4s linear infinite;.

📖 Приклад із підручника (с. 91): плавне мерехтіння через opacity

Рис. 3.4 
.element {
  animation: simpleAnimation 5s infinite;
}

@keyframes simpleAnimation {
  0%   { opacity: 0;   } /* Повністю прозорий */
  25%  { opacity: 0.4; }
  50%  { opacity: 0.8; } /* Майже непрозорий */
  75%  { opacity: 0.4; }
  100% { opacity: 0;   } /* Знову зникає */
}

Властивість opacity змінює прозорість елемента (і всього, що всередині нього) від 0 (невидимий) до 1 (100% непрозорий).

Живий результат (цикл 5 сек)
OPACITY

Блок плавно з’являється до 0.8 і знову розчиняється до 0 без жодного кліку!

🔍 Інтерактивний довідник 8 властивостей animation-*

Натисніть на властивість, щоб побачити пояснення й приклад:
Обов’язкова властивість №1

animation-name — Ім’я сценарію @keyframes

Пов’язує HTML-елемент із конкретним правилом @keyframes. Назва має точно збігатися (регістр літер важливий, без пробілів — наприклад, spin або fadeIn). 

animation-name: spin;
/* Має відповідати @keyframes spin { ... } */

⚡ Короткий запис animation в один рядок (с. 92 підручника)

Так пишуть профі

Замість 6 окремих рядків можна записати все разом: animation: spin 4s linear 0s infinite alternate;

spin1. Назва @keyframes
4s2. Тривалість (duration)
linear3. Динаміка (timing)
0s4. Пауза (delay)
infinite5. Повтори (iteration)
alternate6. Напрямок (direction)
🚀 Золоте правило 60 FPS та доступність (a11y)

1. Анімуйте transform та opacity: Вони обробляються графічним процесором (GPU) і не змушують браузер перераховувати верстку всієї сторінки — анімація завжди буде плавною навіть на недорогому смартфоні.

2. Поважайте комфорт користувача: Для людей, у яких швидкий рух на екрані викликає втому очей, у CSS існує медіазапит @media (prefers-reduced-motion: reduce), який вимикає або уповільнює декоративні анімації.

3. Готові бібліотеки (с. 92 підручника): У великих проєктах часто підключають Animate.css (готові класи підстрибування та появи), Anime.js (складна синхронізація на JS) або візуальні генератори ключів CSS-Animate.

Розділ 4 · Практична робота №8 (с. 93–96)

Практикум: Жива CSS-пісочниця

Закріпіть тему на практиці прямо в браузері — без встановлення програм! Змінюйте CSS-код у редакторі зліва, дивіться миттєвий результат справа та перевіряйте себе за автоматичним чек-лістом.

Завдання 1 · Тренувальна вправа

Квадрат .one → синє коло

Додайте перехід transition-duration і правило .one:hover, щоб при наведенні блок повертався на 90deg, змінював фон на синій та ставав круглим (border-radius: 50%).

Завдання 2 · @keyframes spin

Нескінченне обертання .square

Створіть @keyframes spin (0%: rotate(0deg), 25%: жовтий колір, 100%: rotate(360deg)) і підключіть до .square із 4s linear infinite alternate.

Завдання 3 · Фотогалерея

Плавний zoom .photo-card

Задайте картці transform: scale(0.95) та transition: transform 0.3s ease, а при наведенні збільшуйте масштаб до scale(1.08) або scale(1.1).

🤖 Автоматична самоперевірка вашого CSS-коду: Перевірка коду: 5/5
  • ⬜Задано плавний перехід transition / transition-duration
  • ⬜Є реакція :hover із трансформацією transform
  • ⬜Оголошено сценарій ключових кадрів @keyframes
  • ⬜Підключено animation (назва + тривалість)
  • ⬜Налаштовано повтор або напрямок (infinite / alternate)
  • Помилка 1 — написали transition тільки всередині :hover: Тоді при наведенні кнопка зміниться плавно, а коли приберете мишу — різко «стрибне» назад. Завжди додавайте transition у базовий клас елемента!
  • Помилка 2 — забули вказати час (animation-duration): Якщо написати лише animation-name: spin; без секунд, тривалість дорівнюватиме 0s і елемент не зрушить із місця.
  • Помилка 3 — не збігається назва в @keyframes: Spin і spin — це різні назви для браузера. Перевіряйте регістр літер!
