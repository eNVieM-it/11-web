1. ЩО ТАКЕ CSS ТА ПРИНЦИП КАСКАДУ

Історія створення каскадних таблиць стилів, фундаментальне розділення структури та оформлення, принципи каскадності (Cascade), специфічності (Specificity) та спадкування (Inheritance).

🎨 ЩО ТАКЕ CSS?

CSS (Cascading Style Sheets) — це мова опису зовнішнього вигляду документа, написаного мовою розмітки (HTML або XML).

Якщо HTML відповідає на запитання «Що це за контент?» (заголовок, абзац, кнопка), то CSS визначає «Як цей контент виглядає?» (колір, розмір, шрифт, позиція, анімація).

🌊 ЧОМУ «КАСКАДНІ»?

Слово «каскадний» означає, що стилі можуть надходити з кількох джерел і «стікати» зверху вниз як сходинки водоспаду.

Якщо для одного й того ж елемента задано декілька суперечливих правил, браузер за чіткими правилами каскаду (специфічність селектора, джерело правила, порядок у коді) визначає одне фінальне правило-переможець.

🧬 СПАДКУВАННЯ ВЛАСТИВОСТЕЙ

Спадкування (Inheritance) — механізм, коли дочірні елементи автоматично переймають певні властивості своїх батьківських блоків.

Наприклад, властивості тексту (font-family, color, line-height), задані для <body>, автоматично успадковуються всіма вкладеними абзацами <p> і списками.

2. ТРИ СПОСОБИ ПІДКЛЮЧЕННЯ CSS

Зовнішній файл стилів (External), внутрішні стилі у <head> (Internal) та вбудовані атрибути style (Inline). Порівняння пріоритетів та симулятор каскаду.

Спосіб підключення Синтаксис у коді Де розміщується? Переваги та недоліки Рекомендація W3C
1. Зовнішня таблиця (External) <link rel="stylesheet" href="style.css"> Усередині секції <head> + Єдиний файл для всього сайту.
+ Кешується браузером (швидке завантаження).
+ Чистий HTML без змішування зі стилями. 		★ ГОЛОВНИЙ СТАНДАРТ
2. Внутрішні стилі (Internal) <style> p { color: blue; } </style> Усередині секції <head> + Зручно для швидких односторінкових тестів.
- Не підходить для багатосторінкових сайтів (код доводиться копіювати). 		Тільки для окремих унікальних сторінок
3. Вбудовані / рядкові стилі (Inline) <p style="color: red; font-size: 18px;"> Як атрибут style прямо в тегу HTML + Найвищий локальний пріоритет.
- Засмічує розмітку, складно підтримувати.
- Не дозволяє перевикористовувати стилі. 		⚠ УНИКАТИ (Погана практика)

ЖИВА ДЕМОНСТРАЦІЯ КАСКАДУ

Увімкніть або вимкніть різні способи підключення стилю для одного й того ж елемента. Подивіться, яке правило виграє боротьбу та чому браузер обирає саме його:

📁 1. Зовнішній файл (style.css) Пріоритет: 1 (Базовий)
<link rel="stylesheet" href="style.css">
/* У файлі style.css: */
p { color: #2563eb; } /* СИНІЙ */
📄 2. Внутрішній тег <style> Пріоритет: 2 (Середній)
<style>
p { color: #10b981; } /* ЗЕЛЕНИЙ */
</style>
⚡ 3. Вбудований стиль style="..." Пріоритет: 3 (Найвищий)
<p style="color: #ff4732;"> /* ЧЕРВОНИЙ */
РЕЗУЛЬТАТ ВІДОБРАЖЕННЯ В БРАУЗЕРІ:
Привіт! Якого кольору цей текст?
🏆 ПЕРЕМОЖЕЦЬ: INLINE

Вбудований рядок в атрибуті style="..." перемагає всі правила з файлу та блоку <style>!

ІЄРАРХІЯ ПРАВИЛ У БРАУЗЕРІ:
1. Inline style="..." (Специфічність: 1,0,0,0)
2. Internal <style> (Специфічність: 0,0,0,1)
3. External style.css (Специфічність: 0,0,0,1)

3. БАЗОВІ СЕЛЕКТОРИ CSS

Універсальний селектор (*), селектор тегу, селектор класу (.), селектор ідентифікатора (#), групування селекторів (,) та селектор нащадків (пробіл).

Універсальний селектор * обирає абсолютно всі елементи вебсторінки без винятку. Його найчастіше використовують для так званого «скидання стилів» (CSS Reset), наприклад, встановлення box-sizing: border-box; margin: 0; для передбачуваного розрахунку розмірів.

Селектор тегу (Type Selector) вказує назву HTML-тегу без дужок (наприклад: h1, p, a, button, table). Застосовує стиль до кожного екземпляра вказаного тегу на всій сторінці.

Клас створюється для багаторазового стилізування групи елементів. У CSS селектор класу обов'язково починається з крапки: .card, .button-primary, .badge.

/* У CSS файлі: */
.highlight { background-color: #facc15; font-weight: bold; }

<!-- В HTML документі (БЕЗ КРАПКИ!): -->
<p class="highlight">Важливе повідомлення для учнів</p>

Один HTML-елемент може містити одразу декілька класів через пробіл: <button class="btn btn-blue btn-large">.

Ідентифікатор ID у CSS позначається знаком решітки #. Він призначений для стилізації та адресації одного-єдиного унікального об'єкта на сторінці (наприклад: #main-nav, #site-footer).

За стандартом W3C однаковий id не може повторюватися на одній сторінці двічі! Селектор ID має набагато вищу вагу специфічності за селектор класу.

Групування селекторів (через кому): якщо потрібно надати однаковий стиль різним елементам, їхні селектори перелічують через кому. Це скорочує код і уникає дублювання: h1, h2, h3, .custom-title { font-family: 'Space Grotesk', sans-serif; }.

Селектор нащадків (через пробіл): вибирає елементи лише тоді, коли вони розташовані всередині іншого елемента. Наприклад, nav a { color: white; } змінить колір посилань тільки всередині блоку навігації <nav>, не чіпаючи інші посилання сторінки!

4. СТИЛІ ТЕКСТУ ТА ШРИФТІВ

Властивості сімейства шрифтів font-family, розмір font-size (px, rem), насиченість font-weight, висота рядка line-height, вирівнювання text-align та декорування text-decoration.

Властивість CSS Опис та призначення Типові значення та приклади
font-family Гарнітура (сімейство) шрифту з резервним списком (fallback stack). 'Space Grotesk', Arial, sans-serif, 'Times New Roman', serif, monospace
font-size Розмір кегля шрифту. Рекомендовано використовувати відносні rem. 16px, 1rem, 1.25rem, 2.5rem, 120%
font-weight Насиченість (товщина) літер. normal (400), bold (700), числові значення від 100 до 900
font-style Накреслення шрифту (пряме чи курсивне). normal, italic, oblique
color Основний колір літер тексту. #1e293b (HEX), rgb(37, 99, 235), hsl(217, 91%, 60%), crimson
text-align Горизонтальне вирівнювання тексту всередині блоку. left (по лівому краю), center (по центру), right, justify (по ширині)
line-height Інтерліньяж (висота рядка / міжрядковий інтервал). 1.5, 1.6 (безрозмірний коефіцієнт), 24px, 150%
letter-spacing Трекінг (додатковий простір між літерами). normal, 1px, 2px, -0.5px
text-decoration Оформлення ліній тексту (підкреслення, закреслення). none (зняти підкреслення з посилань!), underline, line-through
text-transform Регістр літер тексту. uppercase (ВСІ ВЕЛИКІ), lowercase, capitalize (Кожне Слово З Великої), none
text-shadow Тінь від тексту (зміщення X, зміщення Y, радіус розмиття, колір). 2px 2px 4px rgba(0,0,0,0.3), 3px 3px 0px #000000

ПРАКТИКУМ №3

Тема: «Оформлення структури вебсторінки: підключення зовнішніх стилів, базові селектори тегів, класів та стилізація текстових елементів».

КРОК 1

Зв'язування файлів

Створіть файл style.css поруч із index.html. У секції <head> підключіть його за допомогою тегу <link rel="stylesheet" href="style.css">.

КРОК 2

Стилі основи <body>

Задайте для body базовий шрифт (font-family), міжрядковий інтервал (line-height: 1.6), колір тексту та фоновий колір сторінки.

КРОК 3

Класи для карток

Створіть класи .user-card, .card-badge та .card-title. Налаштуйте відступи, рамки та плашки категорій.

КРОК 4

Стилізація кнопок

Оформіть посилання-кнопку .card-btn: приберіть підкреслення (text-decoration: none), задайте насиченість font-weight: 700 та тінь box-shadow.
