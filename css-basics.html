Тема 1 · Знайомство без нудьги

1. Що таке CSS та чому він «каскадний»?

Прості життєві аналогії, які допоможуть зрозуміти головний принцип роботи стилів раз і назавжди.

💡 Головна підказка: Будинок, людина та три кити вебу

Усі вебсайти у світі будуються з трьох технологій, кожна з яких має свою чітку роль:

🧱
HTML — це стіни й скелет
Створює заголовок, текст, кнопку чи картинку. Без HTML немає взагалі нічого.
🎨
CSS — це одяг і фарба (Наш урок)
Фарбує стіни в синій колір, робить шрифт красивим, ставить тіні та налаштовує розміри.
⚡
JavaScript — це електрика та розум
Оживляє сайт: двері відчиняються самі, вмикається нічна тема, рахуються бали в тесті.

🧣 Чому стилі називають «каскадними»? (Аналогія з шарами одягу)

Уявіть, що ви вдягли вранці синій светр, а перед виходом на вулицю накинули зверху яскраву червону куртку. Який колір побачать ваші друзі на вулиці? Звісно, червоний! Бо куртка надіта зверху (вона ближча до глядача).
Так само і в CSS: якщо для одного тексту написано декілька правил з різними кольорами, браузер обирає те правило, яке сильніше або ближче.

Тема 2 · Де писати стилі?

2. Три способи підключення CSS

Куди записувати код стилів: у власний окремий файл, нагорі сторінки чи прямо в тег?

📁 1. Окремий файл (style.css)

Як це працює: створюємо поруч файл style.css та підключаємо його одним рядком усередині <head>:

<link rel="stylesheet" href="style.css">

★ Найкращий спосіб! Цей файл можна підключити до 100 різних сторінок одночасно.

📄 2. Усередині тегу <style>

Як це працює: пишемо стилі прямо в шапці <head> конкретної HTML-сторінки:

<style>
  h1 { color: red; }
</style>

Зручно для швидкої перевірки однієї сторінки, але незручно копіювати на весь сайт.

⚡ 3. Прямо в тегу (Inline style)

Як це працює: пишемо атрибут прямо в слові тегу:

<p style="color: red;">Привіт!</p>

⚠ Не рекомендується: сторінка стає брудною, важко знайти і виправити помилку.

⚔️ Гра-симулятор: чий стиль переможе?

спробуйте перемикати прапорці

Увімкніть різні джерела стилю для одного речення. Подивіться, якого кольору стане текст і чому браузер обрав саме його:

1. Зовнішній файл style.css (Синій) Сила: 1
p { color: #2563eb; } /* Синій колір з файлу */
2. Блок <style> у шапці (Зелений) Сила: 1
<style> p { color: #10b981; } </style>
3. Прямо в тегу style="..." (Червоний) Сила: 1000
<p style="color: #ff4732;">Текст</p>
Що показує браузер:
Привіт! Якого я зараз кольору?

Вбудований стиль прямо в тегу переміг, бо він найближче до слова!

2. Блок <style> на сторінці

Тема 3 · Селектори

3. Базові селектори: як покликати потрібний елемент

Уявіть, що ви вчитель у класі. Як ви можете звернутися до учнів? Точно так само працюють селектори в CSS!

Коли ми пишемо просто p { color: blue; }, це означає: «Знайти всі абзаци на сторінці та пофарбувати їх у синій колір».

Селектор * означає «Уся школа без винятку!». Його часто ставлять на початку файлу, щоб прибрати зайві відступи за замовчуванням.

Клас — це як однаковий значок або форма. Будь-який учень може надіти значок чергового. У CSS клас завжди починається з крапки .:

/* У файлі CSS (ставимо крапку!): */
.badge { background-color: yellow; }

<!-- В HTML (БЕЗ крапки!): -->
<span class="badge">Черговий учень</span>

Клас можна давати хоч 100 різним елементам сторінки: кнопкам, картинкам, заголовкам.

Ідентифікатор ID у CSS починається з решітки #. Він дається тільки одному єдиному елементу на всій сторінці (як паспорт або номер телефону):

У класі може бути тільки один староста. Тому однаковий ID ніколи не повинен повторюватися двічі на одній вебсторінці!

Кома , означає «І той, і цей»: h1, h2, p { color: black; } пофарбує і h1, і h2, і p однаково.

Пробіл означає «Тільки якщо лежить всередині»: ul li { color: red; } пофарбує лише ті пункти li, які лежать всередині списку ul.

⚠️ Обережно, граблі! 3 головні помилки початківців

Усі, хто вперше вчить CSS, наступають на ці 3 помилки. Запам'ятайте їх, щоб не витрачати години на пошук:

Помилка №1

Крапка в HTML

У HTML крапку ставити не можна!

❌ <p class=".title">
✅ <p class="title">
Помилка №2

Забута крапка в CSS

У CSS перед класом крапка обов'язкова!

❌ title { color: red; }
✅ .title { color: red; }
Помилка №3

Забута крапка з комою ;

Без ; команди злипаються в кашу:

❌ color: red font-size: 18px
✅ color: red; font-size: 18px;

Тема 4 · Текст та шрифти

4. Стилі тексту: робимо слова виразними

Шпаргалка з перекладом основних англійських слів на зрозумілу українську мову та жива студія шрифтів.

Англійське слово в CSS Що це означає по-простому? Приклад у коді
color Колір букв (не фону!). Можна писати назвами або кодом #121212. color: blue; або color: #ff4732;
background-color Колір підкладки під текстом (як пофарбувати аркуш паперу). background-color: #facc15; (жовтий)
font-family Гарнітура (вигляд) літер: із засічками, рівний або як у програмістів. font-family: 'Space Grotesk', sans-serif;
font-size Розмір літер. 1rem = звичайний текст (16px), 2rem = великий заголовок (32px). font-size: 1.25rem; або font-size: 20px;
font-weight Жирність літер. 400 — звичайний текст, 700 — напівжирний (bold). font-weight: 700;
line-height Повітря між рядками. Щоб рядки не злипалися в очах, ставлять 1.5–1.7. line-height: 1.6;
letter-spacing Відстань між літерами у слові (робить заголовок стильним). letter-spacing: 1px;
text-align Куди притиснути текст: ліворуч (left), по центру (center) чи праворуч (right). text-align: center;
text-decoration: none; Магічне правило, яке знімає синє підкреслення з посилань. text-decoration: none;
