Каскадні таблиці стилів CSS

CSS (Cascading Style Sheets) — це офіційний стандарт W3C для візуального оформлення вебдокументів. Якщо мова HTML визначає логічну структуру та семантику контенту (заголовки, текст, таблиці, посилання), то CSS повністю відповідає за його візуальну презентацію: шрифтову ієрархію, палітру кольорів, сітки розташування блоків (layouts), відступи та адаптивність до екранів будь-яких пристроїв.

1. Що таке CSS та принцип каскадності

Розподіл обов'язків у веб-розробці (Separation of Concerns), принцип каскаду та анатомія CSS-правила.

🏛️ Архітектурний принцип: розподіл обов'язків (Separation of Concerns)

Сучасна веброзробка базується на чіткому розмежуванні ролей між трьома основними технологіями:

🧱 HTML · Структура і семантика
Створює документ та його DOM-дерево за допомогою тегів (заголовки, абзаци, списки, таблиці, посилання). Визначає зміст та ієрархію інформації.
🎨 CSS · Презентація та дизайн
Описує зовнішній вигляд: шрифти, кольори, просторові відступи, сітки розташування та адаптивність до мобільних і десктопних екранів.
⚡ JavaScript · Логіка та динаміка
Реалізує динамічну поведінку: реакцію на події користувача, валідацію форм, інтерактивні анімації та асинхронний обмін даними з сервером.

🌊 Чому таблиці стилів називають «каскадними»? (The Cascade)

Слово «каскадні» (Cascading) вказує на те, що до одного й того самого HTML-елемента можуть одночасно застосовуватися кілька стильових правил із різних джерел. Браузер збирає всі ці правила у єдиний потік («каскад») і вирішує можливі конфлікти за чітким стандартизованим алгоритмом W3C:

1 Джерело та важливість
Браузерні стилі за замовчуванням мають найнижчий пріоритет. Авторські стилі з файлів перекривають їх, вбудовані інлайн-стилі перекривають файли, а директива !important має винятковий пріоритет.
2 Специфічність (вага)
Якщо правила конфліктують на одному рівні, браузер обчислює вагу селекторів. Більш конкретний селектор (наприклад, ID або клас) завжди перемагає загальний селектор тегу.
3 Порядок оголошення
Якщо джерело та специфічність абсолютно однакові, перемагає те правило, яке записане в коді документа пізніше (нижче у файлі).

⚖️ Формула розрахунку специфічності: вектор (Inline, ID, Class, Tag)

Вага будь-якого CSS-селектора обчислюється як 4-значний вектор (A, B, C, D). Порівняння значень здійснюється зліва направо:

Рівень ваги Складова вектора Приклади селекторів Значення ваги
Рівень 1 (Найвищий) Вбудовані інлайн-стилі (Inline) <p style="color: red;"> (1, 0, 0, 0)
Рівень 2 Ідентифікатори (ID) #main-header, #hero-section (0, 1, 0, 0)
Рівень 3 Класи, атрибути, псевдокласи .card, [type="text"], :hover (0, 0, 1, 0)
Рівень 4 (Базовий) Назва елемента (тегу) та псевдоелементи p, h1, div, ::before (0, 0, 0, 1)

2. Три способи підключення стилів до документа

Технічні особливості, переваги, недоліки та практичні рекомендації стандарту W3C.

📁 1. Зовнішня таблиця стилів (External CSS)

Синтаксис підключення: тег <link> усередині секції <head>:

<link rel="stylesheet" href="style.css">

Переваги: промисловий стандарт. Файл кешується браузером після першого запиту, суворо розділяє розмітку та оформлення, може обслуговувати необмежену кількість сторінок проекту.

📄 2. Внутрішня таблиця стилів (Internal CSS)

Синтаксис: блок <style> у шапці <head> HTML-документа:

<style>
  h1 { color: #1e3a8a; }
</style>

Сфера застосування: створення швидких односторінкових прототипів (Landing Pages) або специфічних правил для однієї сторінки. Не підходить для багатосторінкових вебсайтів через дублювання коду.

⚡ 3. Вбудовані інлайн-стилі (Inline Styles)

Синтаксис: глобальний атрибут style="..." безпосередньо в тезі:

<p style="color: #ff4732; font-size: 18px;">...</p>

Особливість: має найвищу специфічність (1, 0, 0, 0), перебиває правила з файлів, ускладнює підтримку і засмічує розмітку. Використовується рідко (наприклад, для динамічних координат).

імітація Browser DevTools (F12)

Оберіть практичний сценарій конкуренції стилів. Панель інспектора праворуч у реальному часі демонструє розрахунок специфічності кожного правила та відображає активні й перекреслені (line-through) властивості, як у консолі веб-розробника:

3. Базові селектори: правила вибору елементів у DOM

Класифікація селекторів за стандартом CSS3, контекстні комбінатори та синтаксичні правила групування.

Селектор тегу знаходить і застосовує правила до всіх екземплярів зазначеного елемента в документі: p { color: #334155; line-height: 1.6; }. Має базову специфічність (0, 0, 0, 1).

Універсальний селектор * обирає абсолютно всі елементи сторінки. У сучасній веброзробці його найчастіше використовують для глобальної нормалізації геометрії блоків: * { box-sizing: border-box; margin: 0; padding: 0; }.

Клас — це основна одиниця побудови компонентного веб-дизайну. Селектор класу у файлі CSS завжди починається з крапки ., а в розмітці HTML записується без крапки:

/* 1. Оголошення у файлі styles.css (з крапкою): */
.badge { background-color: #facc15; font-weight: 700; }

<!-- 2. Використання в HTML-розмітці (БЕЗ крапки): -->
<span class="badge">Новий курс</span>

Один HTML-елемент може містити декілька класів одночасно, розділених пробілом: <button class="btn btn-primary">...</button>. Специфічність: (0, 0, 1, 0).

Ідентифікатор ID у CSS починається з символу решітки #. За стандартом W3C кожен `id` повинен бути строго унікальним у межах одного HTML-документа:

/* CSS-селектор унікального блоку: */
#main-header { position: sticky; top: 0; z-index: 100; }

Окрім стилізації з високою специфічністю (0, 1, 0, 0), ідентифікатори слугують якірними посиланнями для швидкої навігації сторінкою (наприклад, посилання <a href="#main-header">).

Групування селекторів (кома ,): застосовує однаковий набір властивостей до кількох елементів одразу:
h1, h2, h3 { font-family: 'Space Grotesk', sans-serif; }

Селектор нащадків (пробіл): обирає всі елементи, що знаходяться всередині батьківського контейнера на будь-якій глибині вкладеності:
nav a { color: #2563eb; } — знайде всі посилання <a> всередині тегу <nav>.

Дочірній селектор (знак більше >): обирає лише прямих дітей першого рівня вкладеності: ul > li.

⚠️ Типові синтаксичні помилки під час написання CSS

Зверніть особливу увагу на три найпоширеніші помилки, через які браузер ігнорує стильові правила:

Помилка №1

Крапка всередині HTML

В атрибуті class назва пишеться без крапки:

❌ <p class=".title">
✅ <p class="title">
Помилка №2

Пропущена крапка в CSS

Без крапки CSS шукає неіснуючий HTML-тег:

❌ title { color: red; }
✅ .title { color: red; }
Помилка №3

Пропущена крапка з комою ;

Без роздільника ; браузер ігнорує рядок:

❌ color: red font-size: 18px
✅ color: red; font-size: 18px;

4. Стилі тексту та шрифтове оформлення

Властивості оформлення тексту, шрифтовий стек (Fallback), одиниці вимірювання (px vs rem) та жива студія типографіки.

Властивість CSS Призначення та специфікація Синтаксис та приклад у коді
color Колір тексту (символів). Може задаватися ключовими словами (red), HEX-кодом (#2563eb), або функціями rgb(37, 99, 235), hsl(). color: #2563eb;
background-color Колір фону під текстом або фонової підкладки контейнера. background-color: #f8fafc;
font-family Шрифтовий стек (Font Stack): перелік пріоритетних гарнітур через кому від бажаної до резервної (Fallback). Завершується загальним сімейством (sans-serif, serif, monospace). font-family: 'Space Grotesk', system-ui, sans-serif;
font-size Розмір (кегль) шрифту. Рекомендується використовувати відносні одиниці rem (де 1rem = 16px базового шрифту) замість жорстких px для збереження доступності інтерфейсу. font-size: 1.125rem; /* 18px */
font-weight Насиченість (товщина) літер. Числові значення стандарту W3C від 100 до 900 (400 — Normal, 600 — Semi-Bold, 700 — Bold). font-weight: 700;
line-height Інтерліньяж (міжрядковий інтервал). Задається відносним множником без одиниць (1.5–1.7 для оптимального читання параграфів). line-height: 1.6;
letter-spacing Трекінг (міжлітерний інтервал). Додає або зменшує відстань між окремими символами слова (актуально для заголовків). letter-spacing: 0.05em;
text-align Горизонтальне вирівнювання рядків усередині блоку: left, center, right або justify (по ширині). text-align: center;
text-decoration Оформлення ліній тексту: underline (підкреслення), line-through (закреслення) або none (зняття підкреслення з посилань <a>). text-decoration: none;
text-transform Керування регістром символів без зміни HTML: uppercase (УСІ ВЕЛИКІ), lowercase (усі малі), capitalize (Кожне З Великої). text-transform: uppercase;
📐 Чому rem кращий за px? (Accessibility)
Абсолютні пікселі (px) фіксують розмір жорстко. Якщо людина з порушеннями зору збільшить масштаб шрифту в налаштуваннях операційної системи, розміри в пікселях не зміняться.
Одиниця rem (Root EM) розраховується від кореневого тегу <html>. Завдяки цьому інтерфейс автоматично та пропорційно адаптується під потреби кожного читача.
🌐 Підключення Google Fonts
Якщо потрібного шрифту немає на комп'ютері користувача, його підключають безпосередньо з хмарного сховища шрифтів тегом <link> у секції <head>:
<link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@500;700&display=swap" rel="stylesheet">

🏛️ 1. Архітектура та підключення
  • Розподіл обов'язків (Separation of Concerns): HTML формує семантичний каркас, CSS відповідає за візуальну презентацію, JS — за поведінку.
  • Основний стандарт: підключення зовнішнього файлу через <link rel="stylesheet" href="style.css"> усередині секції <head>. Забезпечує кешування та підтримку багатосторінкових вебсайтів.
  • Внутрішні стилі (<style>): використовуються лише для унікальних односторінкових публікацій.
  • Інлайн-стилі (атрибут style): небажані у серйозних проектах через засмічення коду та надвисоку специфічність.
⚖️ 2. Каскад, специфічність та синтаксис
  • Анатомія правила: селектор { властивість: значення; }. Обов'язково ставити крапку з комою наприкінці кожного оголошення.
  • Специфічність: Тег (0,0,0,1) < Клас (0,0,1,0) < ID (0,1,0,0) < Inline (1,0,0,0).
  • Порядок оголошення (Source Order): при однаковій специфічності перемагає правило, записане нижче по коду документа.
  • Директива !important: ламає природний каскад і вважається поганою практикою (anti-pattern).
🔤 3. Шрифти та оформлення тексту
  • Одиниці rem замість px: rem масштабується відповідно до системних налаштувань користувача, що гарантує вебдоступність (Accessibility).
  • Шрифтовий стек (Fallback): завжди вказуйте резервні гарнітури на випадок збою завантаження вебшрифту (наприклад: 'Space Grotesk', system-ui, sans-serif).
  • Читабельність: комфортний інтерліньяж line-height: 1.5–1.7 та достатній контраст між кольором тексту (color) і фоном (background-color).
  • Посилання: text-decoration: none; знімає дефолтне підкреслення з тегу <a>.
