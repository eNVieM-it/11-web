Каскад і специфічність у CSS

Рівень 4 (Базовий) теги

Рівень 4 каже браузеру: «Знайди ВСІХ представників виду» (усі кнопки, усі посилання чи абзаци)[cite: 3]. Одне посилання має вагу (0, 0, 0, 1)[cite: 3]. Якщо побудувати ланцюжок предків для уточнення, наприклад nav ul li a, браузер підсумує кожен тег, і вага зросте до (0, 0, 0, 4), що легко перекриє звичайний селектор[cite: 3].

<!DOCTYPE html> <html> <head> <style> a { color: red; } /* Вага: (0, 0, 0, 1) */ nav ul li a {color: green; } /* Вага: (0, 0, 0, 4) */ </style> </head> <body> <nav> <ul> <li><a href="#">Посилання</a></li> </ul> </nav> </body> </html>

Рівень 4 (Базовий) псевдоелементи

Головне завдання псевдоелементів — чистота HTML-коду[cite: 3]. Вони дозволяють додавати дизайн, іконки, виділення та спецефекти суто через CSS, не засмічуючи розмітку зайвими пустими тегами[cite: 3]. Псевдоелементи потрібні тоді, коли вам треба оформити шматочок вмісту або додати декорацію, але плодити зайві теги в HTML-розмітці не має сенсу[cite: 3]. Вони є частиною 4-го рівня специфічності й додають +1 до колонки D[cite: 3].

⚠️ Залізне правило: ::before та ::after не працюватимуть без властивості content: ""; (навіть якщо лапки порожні)[cite: 3].

::selection (Виділення мишкою): Керує тим, як виглядає текст, коли користувач виділяє його курсором (за замовчуванням у браузерах це синій фон із білим текстом)[cite: 3].

<!DOCTYPE html> <html> <head> <style> a::after { content: "👉 ";} body::selection {background-color: yellow; color: green;} </style> </head> <body> <nav> <ul> <li><a href="#">Посилання</a></li> </ul> </nav> </body> </html>

Уся магія Рівня 3: (0, 0, C, 0)

Уся магія Рівня 3 тримається на одній простій ідеї[cite: 3]:
Рівень 4 каже браузеру: «Знайди ВСІХ представників виду»[cite: 3].
Рівень 3 каже: «Знайди елементи за особливими прикметами або станом»[cite: 3].

В HTML усі теги однакові: <button> і в Африці <button>[cite: 3]. Але на реальному сайті одна кнопка має бути зеленою («Купити»), а інша — червоною («Видалити»)[cite: 3]. Щоб не змінювати всі кнопки одразу, ми вішаємо на конкретний елемент ярлик-наклейку[cite: 3]. Цей ярлик вказується через атрибут class="...", а назву ви вигадуєте самі з голови[cite: 3].

<!DOCTYPE html> <style> .btn-buy { background-color: green; /* Вага: (0, 0, 1, 0) */ } .btn-delete { background-color: red; /* Вага: (0, 0, 1, 0) */ } </style> <button class="btn-buy">Купити</button> <button class="btn-delete">Видалити</button>

Як АТРИБУТИ тегу пов'язані з CSS?

В HTML у тегів повно рідних службових атрибутів[cite: 3]. CSS вміє вибирати елементи прямо за значенням цих атрибутів без створення зайвих класів[cite: 3]. Для цього в CSS використовують квадратні дужки [ ][cite: 3]:

<style> input[type="password"]{background-color: yellow;} </style> <input type="text"> <input type="password">

Псевдокласи

Псевдоклас — це спеціальне слово в CSS, яке позначає тимчасовий стан елемента або його особливе положення, що змінюється саме по собі без переписування HTML[cite: 3]. В CSS псевдоклас завжди позначається однією двокрапкою : і пишеться впритул до селектора (без пробілу)[cite: 3]:

/* --- ЗВИЧАЙНИЙ СТАН (коли мишка десь в іншій частині екрана) --- */ .btn-buy { background-color: lightgreen; /* блідо-зелена */ } .btn-delete { background-color: lightcoral; /* блідо-червона */ } /* --- ПСЕВДОКЛАС :hover (вмикається САМ, коли курсор над кнопкою) --- */ .btn-buy:hover { background-color: darkgreen; /* стає темно-зеленою */ color: white; } .btn-delete:hover { background-color: darkred; /* стає темно-червоною */ color: white; } <button class="btn-buy">Купити</button> <button class="btn-delete">Видалити</button>
Історична довідка: Раніше, на зорі інтернету (наприкінці 90-х), щоб кнопка змінила колір чи картинку під мишкою, верстальникам доводилося писати JavaScript (так звані onmouseover та onmouseout скрипти)[cite: 3]. Це було повільно, незручно і перевантажувало браузери[cite: 3].

Творці стандартів вебтехнологій (консорціум W3C) побачили, що[cite: 3]:
  • Ця дія суто візуальна (це робота CSS, а не логіки сайту)[cite: 3].
  • 99% розробників роблять абсолютно одне й те саме: показують стан під курсором, активне поле чи клік[cite: 3].
Тому цю механіку «зашили» глибоко під капот браузера прямо в рушій CSS[cite: 3].

Рівень 2: Ідентифікатори (id) та Навігаційні Якоря

Це ключове залізне правило стандарту HTML: ідентифікатор (id) на одній сторінці має бути суворо унікальним і існувати лише в одному єдиному екземплярі[cite: 3].

<!DOCTYPE html> <html lang="uk"> <head> <meta charset="UTF-8"> <title>Приклад якірних посилань</title> <style> html { scroll-behavior: smooth; font-family: sans-serif; } nav { position: fixed; top: 0; left: 0; width: 100%; background-color: #333; padding: 15px; } nav a { color: white; text-decoration: none; margin-right: 20px; font-weight: bold; } nav a:hover { color: #ffd700; } section { height: 800px; padding: 80px 20px 20px 20px; } #about { background-color: lightcoral; } #services { background-color: lightgreen; } #contacts { background-color: lightblue; } </style> </head> <body> <nav> <a href="#about">Про нас</a> <a href="#services">Послуги</a> <a href="#contacts">Контакти</a> </nav> <section id="about"> <h2>Секція: Про нас</h2> </section> <section id="services"> <h2>Секція: Наші послуги</h2> </section> <section id="contacts"> <h2>Секція: Контакти</h2> </section> </body> </html>

Рівень 1: Інлайн-стилі (Inline Styles)

Атрибут style="..." прямо всередині тегу має вагу (1, 0, 0, 0)[cite: 3]. Він повністю ігнорує зовнішній CSS і «переїжджає» навіть унікальний селектор за ID #special-text з вагою (0, 1, 0, 0)[cite: 3]:

<p style="color: red; font-size: 20px;">Цей текст червоний через inline-стиль.</p>
