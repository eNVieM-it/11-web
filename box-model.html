ТЕМА 1 · §2.3, с. 56

1. ЩО ТАКЕ БЛОЧНА МОДЕЛЬ (BOX MODEL)?

Блочна модель визначає, як браузер розраховує розмір елемента та його відступи: послідовно контент → внутрішній відступ → рамка → зовнішній відступ.

📖 СКЛАДОВІ БЛОЧНОЇ МОДЕЛІ

  • Content (Контент) — вміст елемента: текст, зображення тощо. Його розмір задається властивостями width та height.
  • Padding (Внутрішній відступ) — простір між контентом і рамкою. Він прозорий і приймає колір фону елемента.
  • Border (Рамка) — лінія, яка обмежує padding і контент. Вона може мати товщину, стиль і колір.
  • Margin (Зовнішній відступ) — простір за межами рамки. Він прозорий і відокремлює елемент від інших елементів на сторінці.
ТЕМА 2

2. ВІДСТУПИ: MARGIN ТА PADDING

Внутрішні відступи (Padding)

Задають простір всередині елемента, від його вмісту до рамки.

padding-top: 10px;
padding-right: 15px;
padding-bottom: 10px;
padding-left: 15px;

/* Короткий запис */
padding: 10px 15px 10px 15px; 
/* або */
padding: 10px 15px;

Зовнішні відступи (Margin)

Задають простір зовні елемента, відсуваючи його від інших.

margin-top: 20px;
margin-right: auto;
margin-bottom: 20px;
margin-left: auto;

/* Центрування блоку по горизонталі */
margin: 0 auto;

/* У посібнику (Практична робота №4, вправа 3) — так само,
   але відступи з усіх боків: */
margin: auto;
📖 ЗВ'ЯЗОК ІЗ ТЕОРІЄЮ (§2.3, с. 56)

Посібник наголошує: width задає ширину контенту блоку, а height — його висоту. Якщо ширину не задано, блок займає всю ширину браузера; якщо висоту не задано, блок дорівнює вмісту (порожній <div> має висоту 0 px і не відображається на сторінці). Тому margin і padding не впливають на ці розміри.

ТЕМА 3

3. РАМКИ: ВЛАСТИВІСТЬ BORDER

Властивість border дозволяє задати рамку навколо елемента. Вона вимагає трьох значень: товщину, стиль і колір.

border: 2px solid black;
border: 4px dashed red;
border: 3px dotted blue;

ТЕМА 4 · ПОГЛИБЛЕННЯ

4. BOX-SIZING

⚠️ ЦЯ ТЕМА — МАТЕРІАЛ ПОЗАД ПРОГРАМОЮ

У посібнику «Вебтехнології» (10 клас) властивість box-sizing не розглядається: у §2.3 і Практичній роботі №4 вона не згадується. Матеріал наведено як доповнення до програми — за ним можна повернутися до довідника MDN.

За замовчуванням у CSS (значення content-box) загальна ширина блоку розраховується як: width + padding + border.

Щоб ширина width включала в себе і padding, і border (що набагато зручніше при верстці), використовують властивість box-sizing: border-box;.

* {
  box-sizing: border-box;
}
🔍 ЗВЕРНІТЬ УВАГУ НА ПРАКТИЧНУ РОБОТУ

У Практичній роботі №4 (с. 62–63) посібника блок задається лише через width, margin, padding-left та border — без box-sizing. Тому вправи посібника виглядають «ширшими», ніж очікуєш. Це нормально: браузер застосовує content-box.
